Atividades Corrigidas

Exemplo 1 - CSS interno

Enunciado: criar uma página HTML simples com o título "Poema" e versos em parágrafos, aplicando estilos CSS dentro do proprio arquivo HTML.

Abrir atividade
Nesta resolução, o CSS aparece dentro da tag <style>.
HTML com CSS interno 
<html>

<head>
    <meta charset="UTF-8">
   <title>Minha pagina Web</title>
   <style>
      h1{
        color: blue; 
        text-align:center;
      }
      p{
        color: blue; 
        text-align:right; 
        background-color:lightgreen;
      }
    </style>
</head>

<body>
  
    <h1>Poema</h1>
    <p>O tempo é:</p>
    <p>Lento para os que esperam</p>
    <p>Rápido para os que tem medo</p>
    <p>Longo para os que lamentam</p>
    <p>Curto para os que festejam</p>

</body>

</html>

Exemplo 2 - CSS externo

Enunciado: refazer a página do poema separando a formatação visual em um arquivo CSS externo chamado estilo.css.

Abrir atividade Ver CSS
HTML 
<html>

<head>
    <meta charset="UTF-8">
   <title>Minha pagina Web</title>
   <link rel="stylesheet" href="estilo.css">
</head>

<body>
  
    <h1>Poema</h1>
    <p>O tempo é:</p>
    <p>Lento para os que esperam</p>
    <p>Rápido para os que tem medo</p>
    <p>Longo para os que lamentam</p>
    <p>Curto para os que festejam</p>

</body>

</html>
CSS 
h1{
  color: blue; 
  text-align:center;
}
p{
  color: blue; 
  text-align:right; 
  background-color:lightgreen;
}

Exemplo IFPI - Imagem e estilo

Enunciado: construir uma pagina sobre o IFPI Campus Campo Maior usando título, imagem, parágrafos e regras CSS externas.

Abrir atividade Ver CSS
HTML 
<html>

<head>
    <meta charset="UTF-8">
   <title>IFPI Campo Maior</title>
   <link rel="stylesheet" href="estilo.css">
</head>

<body>
  
    <h1>IFPI - Instituto Federal do Piauí</h1>
    <p>
        <img src="ifpiLogo.png" width="40%" height="30%">
    </p>

    <p style="text-align:left; color: red;">
        O Instituto Federal do Piauí é uma instituição de grande relevância na
        promoção da educação de qualidade para todas as regiões do estado do 
        Piauí.
    </p>

    <p style="text-align:right;">
       IFPI Campus Campo Maior.     
    </p>

</body>

</html>
CSS 
h1{
  color: green;
  text-align:center;
  font-family: 'Arial';
}

p{
  text-align:center;
  border: 1px solid black;
  background-color: powderblue;
  font-family: 'Arial';  
}
